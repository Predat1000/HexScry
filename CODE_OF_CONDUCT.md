# HexScry Community Code of Conduct

HexScry welcomes people who want to improve reverse-engineering tooling through careful engineering, useful evidence and respectful collaboration.

## Expected conduct

Participants are expected to:

- discuss ideas, code and evidence rather than attacking people;
- give technical criticism clearly and constructively;
- assume good faith while still asking for reproducible evidence;
- respect different experience levels and help newcomers understand project boundaries;
- avoid harassment, discrimination, threats, sexualized conduct, doxxing and sustained personal hostility;
- respect licenses, privacy, confidentiality and the project's clean-room boundary for proprietary tools;
- avoid posting credentials, private samples, exploit details that require confidential handling, or other sensitive material in public threads.

Disagreement is normal. Repeated hostility, intimidation or attempts to derail collaboration are not.

## Scope

This policy applies in HexScry repository discussions, issues, pull requests, reviews and other project-controlled community spaces. It also applies when someone is clearly representing HexScry in an official project capacity.

## Enforcement

Maintainers may edit or remove content, close or lock threads, reject contributions, issue warnings, temporarily restrict participation or permanently ban participants when behavior materially harms the community or project.

Enforcement should be proportionate to the conduct and should distinguish ordinary technical disagreement or mistakes from harassment or abuse.

## Reporting

For ordinary moderation concerns, use the relevant GitHub conversation and ask a maintainer for help when that can be done safely in public.

For sensitive conduct reports, private personal information or security-related material, use the repository's private GitHub reporting channel once enabled. Do not post sensitive evidence publicly merely to prove a report.

## Project principle

HexScry values evidence-first engineering, but "show evidence" is never a license to demand private information, expose someone else's data or turn technical review into personal interrogation.
